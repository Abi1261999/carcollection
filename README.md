# VELORA — Premium Car Collection

A responsive React + TypeScript + Tailwind CSS + Framer Motion automotive collection website.

## Features
- Cinematic hero, animated marque ticker, editorial story section, experience highlights, FAQ and footer.
- Search by make/model, category tabs, make/body-style filters, and price/year sorting.
- Vehicle detail modal with specifications and test-drive CTA.
- Wishlist/favorites toggles and a compare shortlist (up to 3 cars).
- Test-drive booking and general enquiry forms with client-side validation and confirmation state.
- Newsletter email input with client-side confirmation state.
- Responsive desktop/tablet/mobile layouts, motion transitions, keyboard focus styles, and accessible labels.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

### Notes
- This is a frontend demo. Form submissions and newsletter signup currently show local confirmation states; connect an API/CRM to persist them.
- Vehicle pricing/specifications are sample catalogue data for demonstration and should be verified before production use.
- Vehicle imagery is loaded from Unsplash and therefore requires an internet connection.
